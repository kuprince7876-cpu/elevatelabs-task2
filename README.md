# Task 2: Exploratory Data Analysis (EDA)

## Objective
Understand data using statistics and visualizations.

## Tools Used
- Pandas
- Matplotlib
- Seaborn
- Plotly

## Dataset
Titanic Dataset (or any dataset of choice)

## Steps
1. Summary statistics
2. Histograms & Boxplots
3. Correlation matrix & Pairplot
4. Detect patterns, trends, anomalies
5. Feature-level inferences

## Deliverables
- Code files
- Visualizations (PNG images)
- Short explanations
