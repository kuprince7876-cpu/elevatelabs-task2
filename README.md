# Task 2: Exploratory Data Analysis (EDA)

**Dataset:** Titanic Dataset (`Titanic-Dataset.csv`)
**Tools:** Pandas, Matplotlib, Seaborn, Plotly

## What I did
1. Loaded the dataset and checked shape, data types and missing values.
2. Generated summary statistics (mean, median, std, skewness).
3. Created histograms and boxplots for numeric features.
4. Used a correlation matrix and pairplot to study feature relationships.
5. Compared survival by Sex, Pclass and Embarked.
6. Found patterns, anomalies and made feature-level inferences.

## Key findings
- Women had a much higher survival rate than men.
- First class passengers survived more than third class passengers.
- Age has missing values; Fare is right-skewed with many outliers.
- Fare and Pclass are negatively correlated.

- `eda.py` - full code
